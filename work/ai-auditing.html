Creating an AI-driven CD audit agent

As the only content designer on Facebook Core Identity, I created an AI agent named Spruce that let me scale myself—focus on current projects while cleaning up outdated content across Profile.

Tools: Claude Code, internal agents for analytics and diff creation

Prompt architecture is proprietary and covered by NDA. This page shows how Spruce behaves and what it produces—not the underlying prompt text.

how spruce works

severity rubric (public examples)

Severe

Blocks assistive technology or misleads users about privacy or safety.

Moderate

Inconsistent terminology or unclear action labels that add friction.

Nice-to-have

Casing, punctuation or style drift that doesn’t block comprehension.

Accessibility · terminology in review

agent handoffs Spruce → liveness agent Spruce → analytics agent Spruce → diff agent

my role

  • Encoded CD expertise in the prompt as well as severity levels (e.g. a screen reader blocking issue is severe; casing is nice-to-have)
  • Trained Spruce to hand off work to other agents that complete different jobs, such as analyzing string liveness and pulling daily views
  • Ensured Spruce submits diffs as drafts and doesn’t land code directly without review
