Teaching AI what good content design looks like

How do you scale one content designer across an entire product surface?

  • 30 Profile code directories scanned weekly
  • 150+ content issues found
  • 54% increase in diff accuracy over the prompt's lifecycle
  • 23 rounds of prompt testing before I trusted it
My role
CD, Profile Core Identity
Built with
Claude Code, internal analytics and diff tools
Surface
Facebook Profile

The problem

As the only content designer on Facebook's Core Identity team, I had to choose where my attention went. Current projects always felt more urgent than strings that had sat untouched for years, and on Profile, a surface with decades of accumulated content, those strings were everywhere. I could do current projects well or do the audit work.

I needed a way to monitor the codebase continuously, flag issues by severity, and draft fixes for me to review, without that work taking over my week.

The challenge

Build an agent with enough content design judgment to ensure genuinely useful rather than superfluous output.

My approach

I built an agent called Spruce with Claude Code and connected it to internal tools for analytics and diff creation. Three decisions shaped it:

  • A severity rubric. I defined what Spruce should care about most so it could triage instead of flagging everything. The prompt went through 23 rounds of testing before I trusted its judgment.
  • “Don't be a hero” mentality. Before flagging a string, Spruce called other tools for support to check whether it was still live and how many daily views it got.
  • Drafts only. Spruce submitted fixes as draft diffs and never landed code itself. Every change got human review, and engineers' and designers' time stayed protected.

How Spruce works

Severity rubric

High

Blocks assistive technology or translation. Vague or misleading CTA labels. High-traffic surfaces.

Moderate

Inconsistent terminology, or issues on lower-traffic surfaces.

Low

Casing, punctuation, or style drift that doesn't block comprehension.

Results

Spruce scanned 30 Profile directories every week, giving me continuous visibility. Diff accuracy improved 54% over the prompt's lifecycle.

The unexpected win was collaboration. Engineers engaged with my diffs, which opened conversations about content we wouldn't have had otherwise.
